# T-TẠO ẢNH — bản cài cho khách

Vẽ ảnh AI ngay trên máy bạn bằng card NVIDIA (FLUX.2 klein, Z-Image Turbo). Không tốn tiền API. Dùng chung được với T-CHÚA.

## Tải về (luôn là bản mới nhất)

**https://github.com/tanseven102/t-tao-anh-ban-khach/releases/latest/download/T-TAO-ANH-ban-khach.zip**

## Máy cần có
- Windows 10/11, card **NVIDIA từ 6 GB** (RTX 3050 6GB, 3060, 4060…) + driver NVIDIA mới
- Ổ C trống ~50 GB, mạng ổn định (lần đầu tải ~40 GB: thư viện + model)

## Cài đặt
1. Giải nén file zip, bấm đúp **CAI DAT T-TAO ANH.bat**. Máy chưa có Ubuntu (WSL) thì bộ cài tự cài → khởi động lại máy → mở "Ubuntu" đặt tên + mật khẩu → bấm lại file cài.
2. Ngoài Desktop có lối tắt **T-TAO ANH** → bấm mở.
3. Lần đầu màn hình hiện **MÃ MÁY** (16 ký tự) → gửi người bán. Người bán gửi lại **KHOÁ** (chuỗi bắt đầu `AIANH1.`) → dán vào, Enter. Mỗi KHOÁ chỉ chạy trên 1 máy, có hạn.
4. Tool tự tải model (~34 GB, chỉ lần đầu) rồi tự mở trình duyệt **http://localhost:7860**. Cửa sổ đen phải để nguyên — đóng là tắt tool.

**Dùng với T-CHÚA:** mở T-TẠO ẢNH trước, T-CHÚA tự tìm thấy (cổng 7860), không cần dán khoá gì.

## Cập nhật / gia hạn
- Bản mới: tải lại link trên, giải nén, bấm lại **CAI DAT T-TAO ANH.bat** (khoá, model, ảnh giữ nguyên).
- Hết hạn: mở tool → gửi MÃ MÁY cho người bán → dán KHOÁ mới.
