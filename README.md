# T-TẠO ẢNH — bản cài cho khách

Vẽ ảnh AI ngay trên máy bạn bằng card NVIDIA (FLUX.2 klein, Z-Image Turbo). Không tốn tiền API. Dùng chung được với T-CHÚA.

## Tải về (luôn là bản mới nhất)

**https://github.com/tanseven102/t-tao-anh-ban-khach/releases/latest/download/T-TAO-ANH-ban-khach.zip**

## Máy cần có
- Windows 10/11, card **NVIDIA từ 6 GB** (RTX 3050 6GB, 3060, 4060…) + driver NVIDIA mới
- Ổ C trống ~50 GB, mạng ổn định (lần đầu tải ~40 GB: thư viện + model)

## Cài đặt (Windows 10/11) — không cần Ubuntu
1. Giải nén file zip, vào thư mục **T-TAO-ANH**, bấm đúp **T-TAO ANH.exe**.
2. Lần đầu tool tự cài thư viện (10–30 phút).
3. Cửa sổ hiện **MÃ MÁY** → bấm Chép, gửi người bán. Người bán gửi lại **KHOÁ** → dán vào, bấm Kích hoạt.
4. Lần đầu tool tự tải model (~34 GB) rồi tự mở trình duyệt **http://localhost:7860**. Đóng cửa sổ T-TẠO ẢNH là tắt tool.

**Dùng với T-CHÚA:** mở T-TẠO ẢNH trước, T-CHÚA tự tìm thấy (cổng 7860), không cần dán khoá gì.

## Cập nhật / gia hạn
- Bản mới: tải lại link trên, giải nén, bấm **T-TAO ANH.exe** mới (khoá, model, ảnh giữ nguyên).
- Hết hạn: bấm exe → cửa sổ hiện MÃ MÁY → gửi người bán → dán KHOÁ mới.
